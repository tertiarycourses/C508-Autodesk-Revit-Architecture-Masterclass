# Autodesk Revit Architecture Masterclass

A hands-on, two-day Autodesk Revit course: model a building from terrain to roof, document it with dimensions, rooms, area plans and sections, then specify it with families, tags, schedules and issued drawing sheets.

## About the course

Revit is the industry-standard Building Information Modeling (BIM) platform: one coordinated building model drives every plan, section, elevation, schedule and sheet, so a change made anywhere updates everywhere. This course takes you from the Revit interface to a dimensioned, scheduled drawing set. Every topic is followed by hands-on labs built on real Revit models (`LittleHouse.rvt`, `ModelCreation.rvt`) and tag families, so you finish each topic having produced the work yourself.

## Learning outcomes

On completion of this course, you will be able to:

- Produce and visualise 2D/3D technical drawings using Revit
- Create part lists for modeling using Revit
- Assist in design prototyping and create design documentation
- Produce design specification using Revit

## Topics covered

| Day | Topic | What you cover |
|---|---|---|
| 1 | **Topic 1 — Design Modeling in Revit** | BIM and the Revit platform, user interface, file types, site design and toposurfaces, massing, materials, rendering |
| 1–2 | **Topic 2 — Part Lists for Modeling in Revit** | Levels and grids, stacked, basic and curtain walls, doors and windows, roofs, ceilings, floors and openings, stairs and railings, columns |
| 2 | **Topic 3 — Model Documentation** | Dimension types, rooms, area plans, colour fill legends, furniture plans, callout, section and dependent views, object styles |
| 2 | **Topic 4 — Design Specification** | System, loadable and in-place families, schedules, drawing sheets, worksharing, linked CAD and project hygiene |
