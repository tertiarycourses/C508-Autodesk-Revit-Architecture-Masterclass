## Supplementary practice

[Revit 2025 Practice Set](revit-2025-practice-set/README.md) provides ten staged project checkpoints for additional practice with levels, walls, dimensions, doors, components, kitchens, lights, schedules, images, and linked references. The 658 MB binary pack is supplied through the learner Drive Labs folder; GitHub contains its instructions and checksum manifest only. This optional pack reinforces Labs 1, 4, 5, 6, 9, and 12 and does not replace the 12 course labs.
