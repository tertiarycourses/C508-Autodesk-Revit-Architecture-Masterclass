# Supplementary Revit 2025 Practice Set

This optional checkpoint pack extends the 12 course labs with a second, staged architectural project. It is for consolidation and extra practice; it does not replace the metric workflow practised in Labs 1-12.

## Before you start

- Use Autodesk Revit 2025 or later. The ten RVT files identify themselves as Revit 2025 format; Revit 2024 and earlier cannot open them.
- Work on a copy. Open a checkpoint, immediately use **File > Save As > Project**, and add your initials to the filename.
- Treat each RVT as a checkpoint for the named skill. Inspect the Project Browser, Properties palette, view settings, constraints, warnings, and existing elements before editing.
- The supplied `Floorplan.pdf` is an imperial reference drawing (43'-2" x 31'-10"). Use it only for import/link and scale practice. Continue to use metric dimensions for the course project.
- Keep the original checkpoint unchanged so you can reopen it for comparison or recovery.

## Checkpoint route

| Order | Checkpoint and supporting files | Practice task | Reinforces |
|---|---|---|---|
| 1 | `02_01_Levels.rvt` | Audit the existing level and grid datums; add or rename a level, confirm its plan view, then check it in elevation. | Lab 1 - project setup and levels |
| 2 | `02_03_Walls.rvt` | Inspect wall types, base/top constraints, location lines, joins, and room-bounding behaviour; correct one wall run and verify it in plan and 3D. | Lab 5 - walls |
| 3 | `02_04_Dimensions.rvt` | Add aligned and overall dimensions, then move one referenced element and confirm the dimension string updates. | Lab 9 - dimensions |
| 4 | `02_05_Doors.rvt` | Place or replace hosted doors, correct swing/orientation, and verify that door marks remain unique. | Lab 6 - doors and windows |
| 5 | `02_06_Components.rvt` | Place loadable components, inspect type versus instance properties, and replace one component type without losing its host or location. | Labs 6 and 12 - components and families |
| 6 | `02_07_Kitchen.rvt` | Complete or revise the kitchen layout, check clearances in plan, and confirm the components appear correctly in 3D. | Labs 6, 10, and 12 - components and room planning |
| 7 | `02_09_Lights.rvt` | Inspect the reflected ceiling plan, place or adjust light fixtures, then verify visibility and lighting in an appropriate view. | Lab 4 - visualisation; Lab 12 - loadable families |
| 8 | `04_05_Schedules.rvt` | Create or revise a component schedule; add useful fields, sort/group it, and confirm a model edit updates the schedule. | Lab 12 - schedules |
| 9 | `05_02_Images.rvt`, `Scan.png` | Insert the supplied image into a drafting or sheet view, size it deliberately, and confirm it prints clearly without obscuring annotations. | Lab 12 - drawing sheets and presentation |
| 10 | `05_03_Links.rvt`, `Floorplan.pdf`, `Restaurant logo.dwg` | Link one supplied reference, set the positioning and scale, pin it, then inspect Manage Links and unload/reload it. | Lab 12 - linked references and project management |

## Evidence to retain

For each checkpoint you attempt, save:

1. the working RVT under a new filename;
2. one screenshot showing the relevant Properties or Manage Links settings;
3. one screenshot of the completed plan, schedule, sheet, ceiling plan, or 3D view; and
4. a one-sentence note describing what you changed and how you verified it.

## Completion check

The practice set is complete when you can explain the difference between model elements, annotations, loadable components, schedules, images, and linked references, and can show that changes remain coordinated across the relevant Revit views.

Use `MANIFEST.sha256` to verify that the downloaded exercise files are complete and unchanged.
